# 例：白雲母の K–O の g(r)（Teich-McGoldrick ら 2012 の図 4a と同じ種類の図）

Teich-McGoldrick, Greathouse, Cygan, J. Phys. Chem. C 116, 15099 (2012) の図 4a は、白雲母の層間の K⁺ のまわりの酸素の動径分布関数 g(r) を、架橋 O（Oob）と四面体の Al に結合した架橋 O（Oobts）に分けて、298、500、800 K（0.1 MPa）で示したものです。soapff-gui で同じ種類の図を作りました（`fig4a.png`）。

## 手順（GUI）

1. 「新規計算」で `muscovite_2M1_221.extxyz`（2×2×1、672 原子）を選ぶ。
2. 温度（計算設定の MD の条件）を 298、500、800 K にして、それぞれ次を加える：「＋ その他 › soapff の手順 › soapff の緩和」（NVT 10 ps）、「＋ fix › NPT（箱の傾きも含めて全部）」＋ `run 200000`（100 ps、1 atm）、「＋ その他 › トラジェクトリ」（1 ps ごと）、`run 200000`（100 ps）、「最後の構造を書き出す」。
3. 「解析」の SOVA で、「型の組」に `K-ob K-obts`、求める組は「しない」、全原子の組は外し、平衡化として除く時間を 0、フレーム数 100、dr 0.02 Å、r の最大 8 Å。
4. `python make_fig4a.py` で `T298`、`T500`、`T800` の `analysis/sova_pdf.csv` を 1 枚にする。

`T*/` に入力（`in.lammps`、`system.data`、`system.settings`）、出力（`log.lammps`、`final.data`）、解析（`analysis/`）があります（軌道 `traj.lammpstrj` は大きいので git に入れていない）。計算は SSH の計算機で、各温度 5 並列、約 10 分でした。

## 結果

`fig4a.png`（論文の図と同じ形、全 O に対する K–O）、`fig4a_overlay.png`（`paper_fig4a.png`＝論文の図 4a の上に重ねたもの）、`fig4a_split.png`（K–ob と K–obts に分けたもの）。

| | 第 1 ピーク（3 Å） | 第 2 ピーク（4.8 Å） | 第 4 ピーク（7 Å） |
|---|---|---|---|
| 位置（本稿、論文） | 3.0–3.1 Å（3.0 Å） | 4.7–4.8 Å（4.8 Å） | 7.0–7.1 Å（7.0 Å） |
| 298 K の高さ | 4.1（5.3） | 3.5（5.1） | 2.6（3.45） |
| 500 K の高さ | 3.6（4.5） | 3.3（4.15） | 2.5（2.95） |
| 800 K の高さ | 3.1（3.7） | 2.7（3.4） | 2.2（2.5） |

- ピークの位置（3.0、4.8、7.0 Å と、7.9、8.7 Å の肩）は論文と一致しました。K–O は 6.0〜7.6 Å の間で 0 に近く、2.5 Å より近くに O はいません。
- 温度とともにピークが低く広がる傾向も、論文と同じです。
- 一方、**ピークの高さは論文より 15〜35 % 低く**、第 1 ピークの外側（3.7–4.0 Å）と 6.3 Å に論文にない小さな肩があります。論文の値は図から目で読んだものです。
- K–ob の第 1 ピークは 3.1 Å、K–obts は 2.96 Å で、K⁺ のまわりは ob 6 個と obts 6 個の 12 配位でした。

## 論文との違い（高さが低い原因の候補）

論文は 5,376 原子（8×4×2）で、四面体の Al を Loewenstein 則に従って Si₄Al₂ と Si₅Al₁ の環が同数になるように並べ、緩和 1 ns のあと 3 ns を平均しています。ここは 672 原子、共著者の構造（Al の並びが違う）で、緩和 100 ps のあと 100 ps（100 フレーム）の平均、PPPM・0.5 fs です。K⁺ のまわりの環（Si₄Al₂ と Si₅Al₁）の割合と Al の並びが違うと、K⁺ の位置が変わって g(r) の高さと肩が変わるはずですが、どれが効いているかは確かめていません。

`paper_fig4a.png` は論文の図のスクリーンショットで、重ねた図は自分の確認用です（論文などに載せるには出版社の許可が要ります）。
