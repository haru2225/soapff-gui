# 例：白雲母 2M1 の弾性定数と引張・せん断（論文の計算）

白雲母 2M1（KAl₂(AlSi₃)O₁₀(OH)₂）の単位格子を 2×2×1 に繰り返した結晶（672 原子、20.71 × 17.97 × 20.07 Å、β = 95.76°）を、soapff-gui の「＋ 物性」で計算したものです。座標軸は x が a 軸、y が b 軸（単斜晶のユニーク軸）、z が層に垂直です。

## 手順（GUI）

1. 「新規計算」で `muscovite_2M1_221.extxyz` を選ぶ（同梱のライブラリで、全原子が SOAP で決まる。fallback 0、型の照合の食い違い 0）
2. 「＋ 物性」で、弾性定数 0 K、引張・圧縮（x y z、引張、10⁹ /s、最大ひずみ 0.16）、せん断（xy xz yz、固体、10⁹ /s、最大ひずみ 0.2）を選ぶ。共通は 300 K、1 atm、緩和 NVT 10 ps、NPT 20 ps、NPT の方向 tri
3. 実行先を SSH の計算機（8 並列）にして「計算を開始」（19 分）。終わると結果を受け取り、自動で解析する

| フォルダ | 内容 |
|---|---|
| `gui_run/` | 上の手順の入力（`in.lammps`、`system.data`、`system.settings`）、出力（`elastic0.dat`、`mech_*.dat`、`log.lammps`）、GUI の解析（`analysis/summary.txt` と図）。軌道（`traj_*.lammpstrj`）は大きいので入れていない |
| `elastic0_strain_check/` | 0 K の弾性定数のひずみの確認（`e005_np4`、`e005_np2`：ひずみ 0.005 で 4 並列と 2 並列、`e010_np4`：ひずみ 0.01）。論文の 0 K の値は `e005_np4` |
| `local_run/`、`local_run_tension_z16/` | 同じ構造ファイルから、別の計算機（4 並列、ひずみ 0.001 の 0 K、引張とせん断は最大ひずみ 0.10、z の引張は 0.16）で回したもの。300 K の弾性率は `gui_run/` と 3 % 以内で一致 |

300 K の強度（0.5 ps の移動平均の最大）と破断ひずみ：引張 x 14.7（0.102）、y 13.4（0.079）、z 3.5（0.103）、せん断 xy 11.9（0.153）、xz 2.9（0.136）、yz 2.2（0.135）。DelRio ら（2026）の MD は引張 x、y で約 12 GPa、z で約 3 GPa、破断ひずみ x 約 9–10 %、y 約 7 %、z 約 10–11 %。

## 先行研究とのずれ

**実験とのずれ（面内が 30–50 % 硬く、層をまたぐせん断が柔らかい）は ClayFF の性質です。** ClayFF は結晶構造に合うように決めた力場で、陽イオン–O は結合項を持たず、クーロン力と LJ だけでつながっています。弾性率は合わせていません。Teich-McGoldrick らも「面内の弾性応答を一貫して大きく出す」と報告しています。層の間は K⁺ と層の O のクーロン力だけなので、層をまたぐせん断（C44、G_yz）は弱く出ます。実験の値はブリルアン散乱（断熱、天然試料で Fe や Mg を少し含む）で、MD（等温、理想的な組成）とは条件も少し違います。

**同じ ClayFF の Teich-McGoldrick らとのずれ**（0 K の C11、C22、C12 が 35–45 GPa 大きい、C23 が 18 GPa 小さい、300 K の G_xz、G_yz が 39 % 小さい）には、次の違いがあります。

1. **参照の格子**：本稿の応力 0 の箱は a、b、c が 5.152、8.957、19.768 Å で、入力の構造より −0.5、−0.3、−1.5 %、Teich-McGoldrick らの最適化した箱（5.202、9.024、20.079 Å）より −1.0、−0.8、−1.6 % 小さい。彼らの箱は入力（実験の構造）とほぼ同じで、β も入力の 95.7566° のままなので、形を含めて応力 0 まで緩和していない可能性があります（本稿では、`fix box/relax` だけでは原子が緩和しきらず、箱を固定した最小化と 4 回交互に行う必要があった）。箱が小さい（密な）ほど面内は硬くなります。
2. **四面体の Al の配置と K⁺ の位置**：彼らは Kuwahara の構造から Loewenstein 則で Al を置いた（Si₄Al₂ と Si₅Al₁ の環が同数）モデル、本稿は共著者提供の構造の配置です。四面体の Al の隣の O（obts、−1.1688 e）は ob（−1.05 e）より電荷が大きく、層の間の K⁺ はその近くに引かれるので、Al の並び方が層をまたぐ相互作用（C44、C55、C23）を変えます。
3. **0 K の弾性定数の求め方**：彼らはひずみ 5×10⁻⁷ で、C44 は 15.4 ± 12.2 GPa と不確かさが大きい。本稿では PPPM の力で最小化が 50–100 atm の応力を残して止まるため、ひずみ 0.001 でも 5–10 GPa ばらつき、0.005 と 0.01 で一致することを確かめて 0.005 にした（`elastic0_strain_check/`）。ひずみ 0.001 のときの C44 は 16–19 GPa で、彼らに近いが、それはばらつきの範囲だった。
4. **系の大きさと計算条件**：672 原子と 5,376 原子、PPPM（10⁻⁵）と Ewald（10⁻⁴）、時間刻み 0.5 fs と 1 fs、ひずみ速度 10⁹ と 10⁸ /s。弾性率への影響は小さいが、強度は速いほど高く出る。

DelRio らとの強度の差（本稿の方が 10–20 % 高い）は、主にひずみ速度と系の大きさの違いと考えられます（彼らの MD の条件は補足資料にあり、本稿では確かめていない）。破断ひずみと、面内の強度が層に垂直な向きの約 4 倍という関係は同じです。
