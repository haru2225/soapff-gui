# 例：白雲母 2M1 の弾性定数と引張・せん断（論文の計算）

白雲母 2M1（KAl₂(AlSi₃)O₁₀(OH)₂）の単位格子を 2×2×1 に繰り返した結晶（672 原子、20.71 × 17.97 × 20.07 Å、β = 95.76°）を、soapff-gui の「＋ 物性」で計算したものです。座標軸は x が a 軸、y が b 軸（単斜晶のユニーク軸）、z が層に垂直です。

## 手順（GUI）

1. 「新規計算」で `muscovite_2M1_221.extxyz` を選ぶ（同梱のライブラリで、全原子が SOAP で決まる。fallback 0、型の照合の食い違い 0）
2. 「＋ 物性」で、弾性定数 0 K（ひずみ 0.005）、引張・圧縮（x y z、両方、10⁹ /s、最大ひずみ 0.16）、せん断（xy xz yz、固体、＋と－、10⁹ /s、最大ひずみ 0.16）を選ぶ。共通は 300 K、1 atm、緩和 NVT 10 ps、NPT 20 ps、NPT の方向 tri
3. 「計算を開始」（SSH の計算機、8 並列、35 分）。終わると自動で解析し、両方向をまとめた弾性率（Teich-McGoldrick らと同じ求め方）も出る

「＋ 物性」は今の版の soapff-gui にはありません。この計算はそれを削除する前の版（コミット 2c43d80）で行いました。

| フォルダ | 内容 |
|---|---|
| `gui_run_remote/` | 上の手順の入力（`in.lammps`、`system.data`、`system.settings`、`charges.csv`、`report.json`）、出力（`elastic0.dat`、`mech_*.dat`、`log.lammps`）、GUI の解析（`analysis/summary.txt` と図）。論文の 0 K と 300 K の値。軌道（`traj_*.lammpstrj`）とダンプは大きいので入れていない |
| `elastic0_strain_check/` | 0 K の弾性定数のひずみの大きさを決めた確認（`e005_np4`、`e005_np2`：ひずみ 0.005 で 4 並列と 2 並列、`e010_np4`：ひずみ 0.01）と、`tm_cell`：箱を Teich-McGoldrick らの格子に固定した計算。力場（`system.data`、`system.settings`）は `gui_run_remote/` と同じ |

300 K の「両方向」は、Teich-McGoldrick らと同じく、両方向（引張と圧縮、＋と－のせん断）の応力–ひずみをまとめて、|ひずみ| が面内 0.02、層に垂直 0.01、せん断 0.1 以下で直線近似した傾き。Teich-McGoldrick ら 298 K との差は E_x +9、E_y +18、E_z −9、G_xy +6、G_xz −3、G_yz −9 %。「片方向」は引張と＋のせん断のひずみ 0.02 までの傾きで、E_z、G_xz、G_yz が小さく出る（層に垂直な引張と層をまたぐせん断の曲線は原点で曲がっているため）。

300 K の強度（0.5 ps の移動平均の最大）と破断ひずみ（応力が最大の 70 % 未満に下がるひずみ）：引張 x 14.7（0.102）、y 13.4（0.079）、z 3.6（0.107）、せん断 xy 11.8、xz 3.0（0.145）、yz 2.2（0.132）。圧縮はひずみ 0.16 近くまで応力が増え続ける（28–34 GPa）。DelRio ら（2026）の MD は引張 x、y で約 12 GPa、z で約 3 GPa、破断ひずみ x 約 9–10 %、y 約 7 %、z 約 10–11 %。

同じ構造ファイルと同じ手順で、このコンピュータ（4 並列）で回した前の計算とは、力場（`system.data`、`system.settings`）と入力（`in.lammps`）が 1 バイトも違わず、0 K の弾性定数は 1.4 GPa 以内、両方向の弾性率は 1.5 % 以内で一致した（違いは MD のゆらぎ）。

## 先行研究とのずれ

**弾性率の求め方をそろえると、Teich-McGoldrick らとの差は 18 % 以内**になりました（上の表）。初め（片方向、ひずみ 0.02 まで）は層をまたぐせん断が 39 % 小さく出ましたが、主な原因は求め方の違いでした。残る差（面内の E_x、E_y が 9–18 % 大きい）について、以下を考えました。

**実験とのずれ（面内が 30–50 % 硬く、層をまたぐせん断が柔らかい）は ClayFF の性質です。** ClayFF は結晶構造に合うように決めた力場で、陽イオン–O は結合項を持たず、クーロン力と LJ だけでつながっています。弾性率は合わせていません。Teich-McGoldrick らも「面内の弾性応答を一貫して大きく出す」と報告しています。層の間は K⁺ と層の O のクーロン力だけなので、層をまたぐせん断（C44、G_yz）は弱く出ます。実験の値はブリルアン散乱（断熱、天然試料で Fe や Mg を少し含む）で、MD（等温、理想的な組成）とは条件も少し違います。

**同じ ClayFF の Teich-McGoldrick らとのずれ**（0 K の C11、C22、C12 が 35–45 GPa 大きい、C23 が 18 GPa 小さい、300 K の G_xz、G_yz が 39 % 小さい）には、次の違いがあります。

1. **参照の格子（検証して否定）**：本稿の応力 0 の箱は a、b、c が 5.152、8.956、19.762 Å で、Teich-McGoldrick らの最適化した箱（5.202、9.024、20.079 Å、β は入力の 95.7566° のまま）より −1.0、−0.8、−1.6 % 小さい。箱を彼らの格子に固定して原子だけを最小化し、同じ方法（ひずみ ±0.005）で求めると（`elastic0_strain_check/tm_cell/`）、その箱は本稿の力場では x、y、z に −3.5、−2.9、−1.3 GPa の圧力（引張の向き）がかかった状態で、C11、C22、C66 は 269、247、88 GPa と面内はほとんど変わらず、層の間が広がるため C33、C44、C55 が 44.5、3.7、5.2 GPa に下がった。したがって、面内が彼らより硬いのは参照の格子の違いによるものではない。
2. **四面体の Al の配置と K⁺ の位置**：彼らは Kuwahara の構造から Loewenstein 則で Al を置いた（Si₄Al₂ と Si₅Al₁ の環が同数）モデル、本稿は共著者提供の構造の配置です。四面体の Al の隣の O（obts、−1.1688 e）は ob（−1.05 e）より電荷が大きく、層の間の K⁺ はその近くに引かれるので、Al の並び方が層をまたぐ相互作用（C44、C55、C23）を変えます。
3. **0 K の弾性定数の求め方**：彼らはひずみ 5×10⁻⁷ で、C44 は 15.4 ± 12.2 GPa と不確かさが大きい。本稿では PPPM の力で最小化が 50–100 atm の応力を残して止まるため、ひずみ 0.001 でも 5–10 GPa ばらつき、0.005 と 0.01 で一致することを確かめて 0.005 にした（`elastic0_strain_check/`）。ひずみ 0.001 のときの C44 は 16–19 GPa で、彼らに近いが、それはばらつきの範囲だった。
4. **系の大きさと計算条件**：672 原子と 5,376 原子、PPPM（10⁻⁵）と Ewald（10⁻⁴）、時間刻み 0.5 fs と 1 fs、ひずみ速度 10⁹ と 10⁸ /s。弾性率への影響は小さいが、強度は速いほど高く出る。

DelRio らとの強度の差（本稿の方が 10–20 % 高い）は、主にひずみ速度と系の大きさの違いと考えられます（彼らの MD の条件は補足資料にあり、本稿では確かめていない）。破断ひずみと、面内の強度が層に垂直な向きの約 4 倍という関係は同じです。
